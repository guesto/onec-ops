# v0.9.1 — Кавычки в frontmatter навыка

## Исправлено

- Значение `description` в `SKILL.md` взято в двойные кавычки. Текст не изменился.
  Пользователь на Windows получил от `quick_validate.py` ошибку
  `mapping values are not allowed here` в копии навыка, где в описании появилось
  «: » без кавычек: YAML принял его за новый ключ. В кавычках любое двоеточие безопасно.
- `tests/test_skill.py` разбирал frontmatter упрощённо и такую ошибку не ловил.
  Теперь значение без кавычек с «: » или « #» не проходит тест, а внутри кавычек
  запрещены `"` и `\`.

## Проверка

- Frontmatter всех тегов v0.1.0–v0.9.0 и нового `SKILL.md` разобран через
  `yaml.safe_load` без ошибок.
- Строка из сообщения пользователя роняет тест с понятным сообщением.
- Полный набор: 572 теста, покрытие 98%; Ruff без ошибок.

## Заметка для Windows

`quick_validate.py` из skill-creator читает файл в системной кодировке и падает
с `UnicodeDecodeError` на русском тексте. Это не ошибка навыка; запуск
`py -3 -X utf8 quick_validate.py <путь>` решает проблему.

Версия Python-пакета — `0.9.1`. Публикация в PyPI перенесена в v0.9.2.
