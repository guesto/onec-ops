# ТЗ v0.2.3 — GUI-команды: открытие Конфигуратора и клиента

## Цель

Реализовать команды для открытия интерактивного Конфигуратора 
и клиента 1С:Предприятие. Разблокирует полный сценарий: 
развернуть → открыть → работать.

## Область применения

- Разработка: открыть Конфигуратор для правки конфигурации.
- Тестирование: запустить клиент 1С для проверки.
- Автоматизация: запустить обработку в клиенте.
- CI: запустить клиент в headless-режиме (требует DISPLAY).

## Архитектура

    scripts/actions/
    ├── open_designer.py       # open-designer — открыть Конфигуратор
    └── open_enterprise.py     # open-enterprise — открыть клиент 1С

Изменения в `scripts/lib/runner.py`:
- Поддержка `subprocess.Popen` (для --no-wait).
- Реальная проверка работоспособности DISPLAY (через xdpyinfo).
- Флаг requires_gui в Action.

## Функциональные требования

### F-1. open-designer

    onec-ops open-designer --ib <путь> [--user NAME] [--password PWD]
                           [--no-wait]

Ключи 1С:

    DESIGNER /F <ib> [/N <user>] [/P <password>]

Поведение:
- Открывает окно Конфигуратора на реальном DISPLAY.
- По умолчанию ждёт закрытия окна.
- С --no-wait — возвращает управление сразу.

### F-2. open-enterprise

    onec-ops open-enterprise --ib <путь> [--user NAME] [--password PWD]
                             [--execute <файл.epf>] [--c <параметр>]
                             [--no-wait]

Ключи 1С:

    ENTERPRISE /F <ib> [/N <user>] [/P <password>]
               [/Execute <файл.epf>] [/C <параметр>]

Поведение:
- Открывает клиент 1С:Предприятие.
- По умолчанию ждёт закрытия.
- С --no-wait — возвращает управление сразу.
- --execute — запустить обработку.
- --c — передать параметр в 1С.

### F-3. Проверка DISPLAY

Перед запуском GUI-команд:

    def _verify_display(display: str) -> bool:
        """Проверяет, что X-сервер на DISPLAY реально работает."""
        # через xdpyinfo -display <display>

Поведение:
- Если DISPLAY не задан → OneCOpsError с подсказкой.
- Если DISPLAY задан, но X-сервер не отвечает → OneCOpsError.
- Если xdpyinfo недоступен → WARNING и попытка запуска.

### F-4. Sandbox Codex

Если обнаружена песочница Codex (проверка /tmp/.X11-unix):

    raise OneCOpsError(
        "GUI-команды недоступны в sandbox-режиме Codex. "
        "Выполните команду в терминале пользователя."
    )
