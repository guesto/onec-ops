## Функциональные требования

### F-1. Кроссплатформенный запуск 1С

    run_1c(args: list[str], ctx: RunContext) -> CompletedProcess

- Windows: прямой запуск `1cv8.exe`.
- Linux + DISPLAY: прямой запуск `1cv8`.
- Linux без DISPLAY + xvfb-run: `xvfb-run -a 1cv8`.
- Linux без DISPLAY и без xvfb-run: `XvfbNotAvailable`.
- Таймаут 600 с, обработка `TimeoutExpired`.
- Логирование: команда, stdout, stderr, код возврата, длительность.
- Кодировка `utf-8`, `errors="replace"`.
- Маскирование паролей в логах (`/P`, `/ConfigurationRepositoryP`).

### F-2. Проверка окружения

    check_environment(ctx: RunContext) -> None

- Платформа 1С существует и исполняема.
- Linux: `DISPLAY` или `xvfb-run`; иначе — понятная ошибка.
- Опционально: проверка GTK-зависимостей через `ldd 1cv8 | grep "not found"`.

### F-3. Действие create-ib (файловая ИБ)

    onec-ops create-ib --type file --path <path> [--force]

Ключи 1С:

    CREATEINFOBASE "File=<abs_path>" /DisableStartupMessages

Поведение:
- Если каталог `--path` содержит `1Cv8.1CD` и не задан `--force` — ошибка.
- С `--force` — предупреждение и перезапись.
- Создаёт каталог `--path`, если его нет.
- Логирует результат.

### F-4. Действие create-ib (клиент-серверная)

Пока **заглушка**:

    onec-ops create-ib --type server --server <srv> --ref <name>

Возвращает ошибку «Клиент-серверная ИБ будет реализована в v0.1.1».

## Нефункциональные требования

- Python 3.11+.
- Зависимости: `platformdirs`; dev: `pytest`, `pytest-cov`, `pytest-mock`, `ruff`.
- Все пути через `pathlib`.
- Логирование через `logging`, не `print`.
- Unit-тесты: `runner` (5+ сценариев), `platform_check` (3+), `create_ib_file` (3+).

## Критерии приёмки

- AC-1. `onec-ops create-ib --type file --path /tmp/test-ib` создаёт файловую ИБ на Linux с DISPLAY.
- AC-2. Та же команда работает через `xvfb-run` (проверить, убрав DISPLAY).
- AC-3. На Windows работает через `1cv8.exe` (мокается в тестах).
- AC-4. Повторный запуск без `--force` — ошибка «ИБ уже существует».
- AC-5. С `--force` — перезапись.
- AC-6. `pytest -v` — зелёный.
- AC-7. `onec-ops --help` показывает `create-ib`.
- AC-8. `onec-ops create-ib --type server ...` возвращает понятную ошибку про v0.1.1.
