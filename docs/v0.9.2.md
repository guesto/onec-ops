# v0.9.2 — Установка навыка в Kimi Code

## Цель

Навык проверен пользователем в Kimi Code: копия в `~/.kimi-code/skills/onec-ops/`
появилась в каталоге навыков без правок frontmatter, `dump-epf` / `load-epf`,
сборка обработки из XML и настройка платформы отработали. В README не было
инструкции для Kimi Code, а проверка актуальности копий покрывала только Codex.

## Изменения в README

- Kimi Code добавлен в список агентов во вступлении и в разделе «Agent Skill».
- Раздел «Kimi Code»: копия в `~/.kimi-code/skills/onec-ops/` (каталог зависит
  от `KIMI_CODE_HOME`), общий `~/.agents/skills/`, `.kimi-code/skills/onec-ops/`
  для одного проекта, обязательные `name` и `description`, `/reload` вместо
  перезапуска. Симлинки не проверялись — рекомендуется копия.
- «Обновление копий»: один цикл проверяет все установленные копии в
  `~/.claude`, `~/.codex`, `~/.kimi-code` и `~/.agents`.
- «Проверка»: прямой вызов `/skill:onec-ops` в Kimi Code.

Пути и порядок приоритета сверены с документацией Kimi Code:
https://www.kimi.com/code/docs/en/kimi-code-cli/customization/skills.html

## Проверка

- Цикл проверки копий прогнан на временном `HOME`: полная копия — «актуально»,
  копия без `references/` — «устарело», отсутствующие каталоги пропускаются.
- 572 теста, покрытие 98%; Ruff без ошибок. Код утилиты и навык не менялись.
