# ТЗ v0.2.1 — Файловые форматы .cf / .cfu

## Цель

Реализовать выгрузку и загрузку конфигурации и расширений 
в файловых форматах `.cf` (конфигурация) и `.cfu` (расширение).

## Область применения

- Выгрузка конфигурации в `.cf` для бэкапа или переноса.
- Загрузка конфигурации из `.cf` в другую базу.
- Выгрузка расширения в `.cfu`.
- Загрузка расширения из `.cfu`.

## Архитектура

    scripts/actions/
    ├── dump_cf.py       # dump-cf — выгрузка конфигурации в .cf
    ├── load_cf.py       # load-cf — загрузка конфигурации из .cf
    ├── dump_cfu.py      # dump-cfu — выгрузка расширения в .cfu
    └── load_cfu.py      # load-cfu — загрузка расширения из .cfu

## Функциональные требования

### F-1. dump-cf

    onec-ops dump-cf --to <файл.cf>

Ключи 1С:

    DESIGNER /F <ib> /DisableStartupDialogs /DumpCfg <файл.cf>

Валидация:
- --ib содержит 1Cv8.1CD.
- Родительский каталог --to доступен для записи.

### F-2. load-cf

    onec-ops load-cf --from <файл.cf> [--update-db-cfg]

Ключи 1С:

    DESIGNER /F <ib> /DisableStartupDialogs /LoadCfg <файл.cf> [/UpdateDBCfg]

Валидация:
- --ib содержит 1Cv8.1CD.
- Файл --from существует и непустой.

### F-3. dump-cfu

    onec-ops dump-cfu --to <файл.cfu> --extension <имя>

Ключи 1С:

    DESIGNER /F <ib> /DisableStartupDialogs 
      /DumpCfg <файл.cfu> -Extension <имя>

Валидация:
- --ib содержит 1Cv8.1CD.
- --extension задан.
- Родительский каталог --to доступен для записи.

### F-4. load-cfu

    onec-ops load-cfu --from <файл.cfu> --extension <имя> [--update-db-cfg]

Ключи 1С:

    DESIGNER /F <ib> /DisableStartupDialogs 
      /LoadCfg <файл.cfu> -Extension <имя> [/UpdateDBCfg]

Валидация:
- --ib содержит 1Cv8.1CD.
- --extension задан.
- Файл --from существует и непустой.

## Тесты

Для каждого действия:
- validate: отсутствующие параметры → OneCOpsError.
- validate: несуществующий файл → OneCOpsError.
- validate: OK → проходит.
- build_1c_args: корректная команда 1С.
- Для cfu: обязательность --extension.

## Критерии приёмки

- AC-1. `dump-cf --to /tmp/base.cf` создаёт .cf.
- AC-2. `load-cf --from /tmp/base.cf` загружает конфигурацию.
- AC-3. Round-trip: `dump-cf → load-cf` в новую базу.
- AC-4. `dump-cfu` / `load-cfu` работают с расширениями.
- AC-5. `pytest -v` зелёный.
- AC-6. Skill обновлён: 4 новые команды.
- AC-7. README обновлён.

## Ограничения

- `.cfu` — файл обновления конфигурации, не путать с `.cfe` (расширение).
- Для `.cfu`/`.cfe` ключи 1С используют `-Extension <имя>`.
- Точный синтаксис проверим на реальной платформе 8.5.1.1343.
