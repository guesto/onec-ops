# onec-ops

CLI-утилита и Agent Skill для автоматизации пакетных операций 1С:Предприятие.

## Статус

В разработке. Текущая версия: v0.1.0 (в процессе).

## Требования

- Python 3.11+
- Платформа 1С:Предприятие 8.3.x (толстый клиент `1cv8`)
- Linux: `xvfb` (опционально, для headless-режима)
- Windows: платформа 1С установлена стандартно
