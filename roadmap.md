# Roadmap onec-ops

CLI-утилита и Agent Skill для автоматизации пакетных операций 1С:Предприятие.

## Принципы

- **Итеративность.** Каждый релиз — маленький, проверяемый, с тестами.
- **Кроссплатформенность.** Linux + Windows, DISPLAY + xvfb-run.
- **Двойное назначение.** Утилита работает и для человека (CLI), и для ИИ-агента (Agent Skill).
- **Чистые тесты.** Никаких реальных запусков 1С в unit-тестах — только моки subprocess.
- **Проверенные решения.** Лучшие куски из первой попытки переиспользуются.

## Релизы

### v0.1.0 — Фундамент: дисплей + файловая ИБ

- Кроссплатформенный `runner` (Linux DISPLAY / xvfb-run, Windows direct).
- Проверка окружения: `DISPLAY`, `xvfb-run`, GTK-зависимости.
- Команда `create-ib --type file --path <path>` — создание файловой ИБ.
- Unit-тесты на `runner`, `platform_check`, `create-ib`.
- README с требованиями и примерами.

### v0.1.1 — Клиент-серверная ИБ

- Проверка наличия сервера 1С (`ragent`, `rmngr`, `rphost`).
- Команда `create-ib --type server --server <srv> --ref <name>`.
- Документация по подготовке серверной среды.
- **Зависит от:** установленного и запущенного сервера 1С.

### v0.2.0 — Конфигурация (XML)

- `dump-config` — выгрузка конфигурации в XML.
- `load-config` — загрузка конфигурации из XML.
- Round-trip тест на реальной базе.

### v0.3.0 — Внешние обработки (XML)

- `load-epf` — сборка `.epf` из XML.
- `dump-epf` — разборка `.epf` в XML (с учётом ограничений платформы).
- Round-trip тест.

### v0.4.0 — Бэкапы базы (DT)

- `dump-dt` — выгрузка базы в `.dt`.
- `restore-dt` — восстановление из `.dt`.

### v0.5.0 — Хранилище конфигурации

- `repo-create` — создание хранилища.
- `repo-bind` — подключение базы к хранилищу.
- `repo-update` — обновление из хранилища.
- `repo-add-user` — добавление пользователя.

### v0.6.0 — Расширения

- `load-extension` — загрузка `.cfe` в ИБ.
- `dump-extension` — выгрузка расширения в XML.
- `load-extension-xml` — загрузка расширения из XML.

### v0.7.0 — Agent Skill

- `SKILL.md` с frontmatter для Codex и Claude Code.
- `agents/openai.yaml`.
- `references/` с детальными описаниями команд.
- Инструкции по symlinks в `.agents/skills/` и `.claude/skills/`.

### v0.8.0 — Обновление конфигурации БД

- `update-db` — обновление конфигурации БД (`/UpdateDBCfg`).
- Поддержка `--dynamic` для динамического обновления.

### v0.9.0 — Полировка и CI

- GitHub Actions: тесты на Linux + Windows, Python 3.11–3.14.
- Линтер `ruff`, форматирование, pre-commit.
- Покрытие тестами ≥ 80%.
- Публикация в PyPI (`pipx install onec-ops`).

### v1.0.0 — Стабильный релиз

- Документация: README, CHANGELOG, CONTRIBUTING.
- Все команды проверены на реальной 1С.
- Skill протестирован в Codex и Claude Code.
- Семантическое версионирование, стабильный API.

## Вне scope

- Windows-специфичные фичи (COM-интеграция и т.п.).
- Работа с кластером серверов 1С через `ras`/`rac` (кроме v0.1.1).
- Публикация на веб-сервере.
- GUI.
